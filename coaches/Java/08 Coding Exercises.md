# 08 Coding Exercises

Classic hands-on exercises — ask the candidate to talk through (or write) an
implementation, then probe complexity and edge cases.

- Reverse a String without using any built-in reverse methods.
- Find the duplicate elements in an array.
- Check whether a String is a palindrome.
- Implement an LRU cache.
- Implement the producer-consumer problem.
- Find the first non-repeating character in a string.
- Detect a cycle in a linked list.
- Find the top-K frequent elements in a collection.
