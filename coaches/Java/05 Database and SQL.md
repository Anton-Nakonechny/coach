# 05 Database and SQL

Relational fundamentals and the Hibernate/JPA pitfalls that show up once a Java
service starts talking to a real database under load.

- What is the difference between INNER JOIN and LEFT JOIN?
- What are indexes, and how do they change query performance?
- What is the difference between COUNT(*), COUNT(1), and COUNT(column)?
- How would you optimize a slow query?
- Explain the ACID properties of a transaction.
- What is database normalization, and why would you normalize or denormalize a schema?
- What is the Hibernate N+1 query problem, and how do you detect and fix it in production?
